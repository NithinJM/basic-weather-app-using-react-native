# Weatherly

A React Native weather app built with Expo and TypeScript.

## Run the app

```sh
npm install
npm start
```

Use Expo Go to open the QR code, or run `npm run android` / `npm run ios` with a configured simulator.

The app loads a local forecast on launch, lets you search for cities, switch between Celsius and Fahrenheit, and request device location. Forecast and geocoding data come from Open-Meteo and do not require an API key.

Use a Node.js version supported by Expo SDK 58 (22.13+, 24.3+, or 26+).
